# MyDesk Releases

**MyDesk** is a personal Windows desktop application designed to bring everyday productivity tools together in one place.

## Features

- Calendar and event management
- Task tracking
- Notes and quick memos
- Income and expense tracking
- Desktop notifications
- Local data storage and backups
- Automatic application updates

## Installation

Visit the [Releases page](https://github.com/TPertev/MyDesk-releases/releases) to download the latest Windows installer.

Download `MyDesk-Kurulum-x.x.x.exe` and run it to install MyDesk.

## Updates

MyDesk checks for new versions automatically through this public GitHub Releases repository.

## Platform

- Windows
- Electron
- React
- TypeScript
